Персональный сайт-визитка — Гниятуллин Ислам

Современный, интерактивный сайт-визитка (портфолио), разработанный с использованием передовых техник веб-дизайна. Проект сочетает в себе высокую производительность, эстетику минимализма и удобство пользователя.

Особенности проекта
- Parallax Hero Section: Эффект «погружения» главного фото под интерфейс при прокрутке.
- Glassmorphism Design: Использование эффекта матового стекла для карточек навыков и контактов.
- Интерактивность: 
  - Анимированное имя с градиентным переливом.
  - Кастомный курсор, реагирующий на взаимодействие.
  - Индикатор прогресса чтения страницы (Scroll Progress Bar).
  - Пульсирующие иконки соцсетей при наведении.
- Атмосферный фон: Плавающие неоновые сферы и мягкое свечение по краям страницы.
- Адаптивность: Сайт полностью корректно отображается на ПК, планшетах и смартфонах.

Технологический стек
   HTML5 — семантическая структура.
   CSS3 — продвинутая анимация, Flexbox, Grid Layout.
   JavaScript (ES6+) — логика курсора, индикатор скролла и анимационные эффекты.
   FontAwesome — векторная графика и иконки.

Инструкция по запуску
1.  Локально: Просто откройте файл `index.html` в любом современном браузере.
2.  GitHub Pages: 
    - Загрузите файлы в публичный репозиторий.
    - Перейдите в `Settings` -> `Pages`.
    - Выберите ветку `main` и нажмите `Save`.
    - Через минуту сайт будет доступен по адресу `https://github.io`.
